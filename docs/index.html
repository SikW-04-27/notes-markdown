看到「Apple 无法验证」？从这里继续

这是 macOS 的首次打开确认。确认安装包来自本项目的 GitHub 发布页，且文件完整后，按以下步骤操作。

  1. 选择弹窗里的 完成，保留 App。
  2. 打开 系统设置 → 隐私与安全性，向下滚动到「安全性」。
  3. 找到 Notes Markdown 被阻止打开的提示，点击 仍要打开。
  4. 按系统提示认证，并确认 打开。App 内的使用引导会在启动后出现。

找不到「仍要打开」时，再从「应用程序」双击 App，点「完成」，然后回到隐私与安全性页面。组织管理的 Mac 可能需要管理员允许安装。遇到已知恶意软件或文件损坏提示时，请停止打开并核对来源和校验值。

使用时遇到问题？

先检查权限、自动转换开关和光标位置。引导窗口会保留转换失败的原因。

反馈问题 ↗
输入后没有转换怎么办？

确认辅助功能权限和「自动转换」开关都已开启。把光标放到苹果备忘录正文的空行，逐字键入 **你好**。整段粘贴会跳过转换。标题和列表需要在行首输入标记后按空格。

关闭窗口后怎么找到它？

点击屏幕顶部的 Notes Markdown 菜单栏图标，选择「开始使用与试写」。同一个菜单可以暂停、恢复自动转换或退出。

更新后权限失效怎么办？

先退出 App。在系统设置的辅助功能列表移除旧条目，再添加「应用程序」文件夹里的新 App，然后重新打开。

支持哪些 Mac？

预览安装包适用于 Apple 芯片 Mac，最低系统要求为 macOS 13。实际输入已在 macOS 15.3.1 上验证。其他系统版本和账户类型仍需进一步验证。

它会怎样处理笔记和剪贴板？

转换在本机进行。应用通常读取光标前最多 2,048 个 UTF-16 单元。如果局部读取失败，会先取得整篇正文，再检查长度，超过 200,000 个 UTF-16 单元时跳过处理。行内转换会备份剪贴板、临时粘贴富文本并恢复原内容，期间有新剪贴板内容时保留新内容。

可以用它处理 Markdown 文件吗？

这个工具处理正在输入的语法。macOS 26 的备忘录还提供 Markdown 文件导入流程，具体步骤见 Apple 的导入说明。

源码和许可证在哪里？

完整 Swift 源码与构建脚本放在 GitHub 仓库。项目使用 MIT 许可证，可按许可证条款使用、修改和再分发。
