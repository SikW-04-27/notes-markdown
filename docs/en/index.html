Apple cannot verify the app? Start here.

This is the macOS first-launch check. Confirm that the app came from this project's GitHub release and is intact, then follow these steps if you trust the download.

  1. Choose Done in the alert to keep the app.
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Find the message about Notes Markdown being blocked and click Open Anyway.
  4. Authenticate as requested and confirm Open. The app's setup window appears after launch.

If the button is missing, try opening the app from Applications again, choose Done, and return to Privacy & Security. A managed Mac may require an administrator. For malware or damaged-file alerts, stop opening the app and check its source and checksum.

Download and open

Unzip the preview, open 00-先读我-START-HERE.html for the offline guide, and move Notes Markdown.app to Applications. Complete the macOS first-launch confirmation and open the app. Setup shows your current permissions and conversion status.

Click 打开苹果备忘录 (Open Apple Notes). Create a test note and type **hello** character by character on a blank line in the body. The word becomes bold.

Press ⌘Z in Notes to undo. Paragraph conversions may need two undo steps. This release supports small insertions and single-line syntax.

Check permissions, the conversion switch, and your cursor position first. Setup keeps the reason visible if a conversion fails.

Report an issue ↗
Why does my text stay unchanged?

Enable Accessibility and 自动转换 (Automatic conversion). Type **hello** character by character on a blank line in the Apple Notes body. Bulk pastes skip conversion. For headings and lists, type the marker at the start of a line and then press Space.

Where is the app after I close setup?

Open the Notes Markdown menu bar icon and choose 开始使用与试写 (Setup and practice). The same menu lets you pause, resume, or quit.

How do I restore permissions after an update?

Quit the app, remove its old Accessibility entry in System Settings, add the new app from Applications, and reopen it.

Which Macs are supported?

The preview ZIP is for Apple silicon Macs running macOS 13 or later. Live typing has been verified on macOS 15.3.1. Other versions and account types need further testing. The app interface is currently in Simplified Chinese.

How are my notes and clipboard handled?

Conversion runs locally. The app normally reads up to 2,048 UTF-16 code units before the cursor. If a local read fails, it fetches the full body and then checks its length, skipping processing above 200,000 units. Inline conversion backs up the clipboard, pastes rich text, and restores the backup. Newer clipboard contents take precedence.

Can I use this with Markdown files?

The app converts syntax while you type. Notes on macOS 26 also provides a file-import workflow. See Apple’s import guide for those steps.

Where can I find the source and license?

The Swift source and build scripts are on GitHub. The MIT license allows use, modification, and redistribution under its terms.
